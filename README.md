# 수능대비 지문분석 앱

영어 지문을 입력하면 수능 대비 학습자료 6종을 자동 생성하는 웹앱입니다.

1. 단어목록
2. 문장별 해석 (자연스러운 해석 + 직독직해)
3. 중요 문법·구문
4. 문장구조분석 (S/V/O/C/M 성분, 절, 문장 형식)
5. 수능 유형별 문제 (14개 유형)
6. 정답지 (정답, 해설, 오답 이유)

### 인쇄 · PDF · Word 저장
결과 화면의 **🖨️ 인쇄 · PDF · Word** 버튼을 누르면 내보낼 섹션을 고를 수 있습니다.
- 섹션: 표지(원문 지문, 목차, 이름 칸), ①~⑥ 각 섹션. **섹션마다 새 페이지에서 시작합니다.**
- 빠른 선택: 전체(교사용) / 학생용(정답지 제외) / 문제지만 / 문제 + 정답지
- **인쇄 / PDF 저장**: 브라우저 인쇄 창이 열립니다. PDF는 '대상'에서 'PDF로 저장'을 고르세요. 파일 이름은 `수능지문분석_날짜_구성.pdf`로 제안되고, 쪽 번호(Chrome·Edge)와 섹션 머리글이 붙습니다.
- **Word로 저장**: `.docx` 파일을 바로 내려받습니다. 섹션마다 Word 구역이 나뉘어 새 페이지에서 시작하고, 머리글·쪽 번호·문장 성분 색과 밑줄이 그대로 들어갑니다. 한글(HWP)과 Word에서 열어 고칠 수 있습니다.
- 지금 보고 있는 탭만 빠르게 인쇄하려면 **이 탭만 인쇄**를 누르세요.

### 지문 여러 개 한꺼번에 처리
- 지문을 최대 10개까지 넣을 수 있습니다. **+ 지문 추가**로 칸을 늘리거나, 여러 지문이 든 파일을 올리면 지문별로 자동으로 나눕니다.
- 지문마다 이름(예: 18번)을 붙일 수 있고, 시험지에 문항 번호가 보이면 자동으로 붙습니다. ↑↓로 순서를 바꿀 수 있습니다.
- 한 칸에 여러 지문을 통째로 붙여 넣었다면 **AI로 지문별 나누기**를 누르세요 (450단어를 넘으면 나타남).
- 결과 화면 위쪽에서 지문을 골라 볼 수 있고, 지문마다 진행 상황(✓, ⚠)이 표시됩니다.
- 인쇄·PDF·Word에는 **지문1의 섹션들 → 지문2의 섹션들 → …** 순서로 들어가며, 섹션마다 새 페이지에서 시작합니다. 머리글에 지문 이름이 붙습니다.
- **정답지는 맨 뒤에 모으기**를 켜면 문제지는 지문별로, 정답지는 마지막에 모아서 나옵니다. **지금 보고 있는 지문만** 내보낼 수도 있습니다.
- 요청 한도(429)에 걸리면 자동으로 기다렸다가 다시 보냅니다.

### 지문 입력 방법
- **직접 붙여 넣기**
- **📷 사진 찍기**: 휴대폰에서는 바로 카메라가 열립니다. 지문이 두 쪽에 걸치면 한 장씩 찍고 "기존 내용 뒤에 이어 붙이기"를 누르세요.
- **📁 파일 올리기 / 끌어다 놓기**: 사진(JPG·PNG·WEBP, 최대 8장), PDF(1개), TXT
  - 사진과 PDF는 Claude가 글자를 읽어 영어 지문 본문만 뽑습니다 (문항 번호, 한국어 발문, 선택지, 각주는 제외).
  - 지문이 여러 개면 지문별로 나눕니다. 순서배열·문장삽입 문제처럼 나뉜 지문은 원래 글로 이어 붙입니다.
  - 사진은 업로드 전에 브라우저에서 긴 변 1800px JPEG로 줄입니다. 요청 1건은 최대 4MB입니다.
  - 흐려서 추정한 단어나 빈칸(____)이 있으면 경고를 보여줍니다. 뽑힌 글은 생성 전에 꼭 확인·수정하세요.
  - TXT는 `===` 나 `---` 만 있는 줄로 지문을 나눕니다. 구분선 없이 길면 AI가 지문별로 나눕니다.
  - Word(.docx)와 HEIC는 지원하지 않습니다. HEIC는 Safari에서는 자동 변환되고, 다른 브라우저에서는 JPG로 바꿔 올려야 합니다.

## 가장 쉬운 실행: HTML 파일 하나 (설치 없음)

[`dist/suneung-analyzer.html`](dist/suneung-analyzer.html) 파일을 내려받아 **더블클릭**하면 브라우저(Chrome·Edge 권장)에서 바로 실행됩니다.

1. 처음 열면 맨 위에 **API 키** 입력칸이 나옵니다. 아래 둘 중 하나의 키를 넣으세요. 키 모양으로 자동 인식합니다.
   - **Google AI Studio (Gemini)**: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 발급, `AQ.…`로 시작(2026년 5월부터 새로 만드는 인증 키). 기본 모델 `gemini-3.8-flash`. `AIza…`로 시작하는 예전 표준 키는 2026년 9월부터 Gemini API가 거부하므로 새 키를 만드세요.
   - **Anthropic (Claude)**: [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 발급, `sk-ant-…`로 시작. 기본 모델 `claude-sonnet-5-5`
2. 키는 **그 브라우저에만** 저장되고 해당 회사 API로만 보내집니다. 공용 기기에서는 다 쓴 뒤 '변경 → 키 지우기'를 누르세요.
3. 나머지 기능(사진·파일 입력, 여러 지문, 인쇄·PDF·Word 저장, 기록)은 서버판과 같습니다.

- 서버 없이 브라우저가 AI API를 직접 부르므로 인터넷 연결이 필요하고, API 사용 요금은 키 주인에게 청구됩니다.
- Gemini 무료 등급은 분당·하루 요청 수가 적습니다. 지문 1개에 요청이 `4 + 문제 유형 수`만큼 나가므로, 한도에 걸리면 앱이 기다렸다 다시 보내지만 하루 한도를 넘으면 다음 날까지 실패합니다. 문제 유형을 줄이면 요청이 줄어듭니다.
- Gemini 모델이 혼잡하면(503 "high demand") 자동으로 `gemini-3.6-flash` → `gemini-3.5-flash-lite` 로 바꿔 계속 진행합니다. 혼잡했던 모델은 5분 동안 뒤로 미룹니다.
- 휴대폰에서는 파일을 **Chrome 등 브라우저로** 여세요. 메신저·앱의 미리보기 화면은 인터넷 요청을 막을 수 있습니다.
- 생성 기록은 그 브라우저에 저장됩니다. 다른 컴퓨터·브라우저에서는 보이지 않습니다.
- HTML 파일을 다시 만들려면: `pnpm install && pnpm build:html` → `dist/suneung-analyzer.html`

## 서버로 실행 (Next.js)

필요한 것: Node.js 20 이상, pnpm, Anthropic API 키

```bash
pnpm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 값을 채워 넣으세요
pnpm dev                     # http://localhost:3000
```

```bash
pnpm test        # 단위 테스트 (LLM 호출 없음)
pnpm typecheck   # 타입 검사
```

## 동작 방식

```
지문 입력 → 문장 분리(코드, s1·s2…) ─┬─ 단어목록   ┐
                                    ├─ 해석       │  섹션·문제 유형마다 API를 따로 호출
                                    ├─ 문법·구문  │  (동시 4개), 끝난 섹션부터 화면에 표시
                                    ├─ 문장구조   │
                                    └─ 문제 × 유형 ┘
                                         ↓
              LLM(JSON) → Zod 형태 검사 → 지문 대조 검증 → 코드가 문제 조립
                    ↑______ 규칙 위반 시 오류 내용을 알려주고 최대 2회 재시도
```

품질을 위해 지킨 원칙:

- **오프셋은 코드가 계산합니다.** LLM에는 원문 구절을 그대로 받고, 위치는 `lib/align.ts`가 찾습니다. LLM은 글자 수를 정확히 세지 못하기 때문입니다.
- **지문 변형은 코드가 합니다.** 순서배열·문장삽입·무관한 문장·빈칸·어법·어휘 문제는 LLM이 정한 문장 ID와 구절을 바탕으로 `lib/assemble.ts`가 시험지를 조립합니다.
- **정답 번호가 한쪽으로 쏠리지 않게 합니다.** 선택지는 서버에서 섞습니다. 위치가 의미 있는 유형(어법·어휘·내용일치)은 코드가 정답 위치를 무작위로 정해 LLM에 지시합니다. 순서배열은 (A)(B)(C) 라벨을 코드가 무작위로 붙입니다.
- **문제와 정답은 한 번에 생성합니다.** 그래서 문제와 정답지가 어긋나지 않습니다.
- **한 섹션이 실패해도 나머지는 표시됩니다.** 실패한 섹션은 "다시 생성"으로 그것만 다시 만듭니다.

  PassageUpload.tsx           사진 찍기·파일 올리기·끌어다 놓기

  align.ts                    구절 → 오프셋
  validators.ts               섹션별 지문 대조 검증

  prompts/                    LLM 프롬프트
  history.ts                  브라우저 기록 (최근 10건)
  upload.ts / image.ts        파일 판별·추출 텍스트 정리 / 사진 축소
  extract.ts                  사진·PDF 글자 추출 (Claude 비전)
  docx-export.ts              Word(.docx) 문서 생성
  print-sections.ts           내보내기 섹션 목록·출력 순서

## 설정 (`.env.local`)

| 변수 | 설명 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Anthropic API 키 (필수) | — |
| `ANTHROPIC_MODEL` | 사용할 모델 | `claude-sonnet-5-5` |
| `RATE_LIMIT_PER_MINUTE` | IP당 분당 요청 수 | `40` |

## 원래 요구사항(docs/PROMPT.md)과 달라진 점

- 진행 상태는 SSE 대신 **섹션별 API 개별 호출**로 보여줍니다. 구현이 단순하고 재생성도 쉽습니다.
- 지문 1건에 요청이 `4 + 문제 유형 수`만큼 나가서, rate limit을 분당 5회에서 **분당 40회**로 올렸습니다.
- 메모리 기반 rate limit은 서버 인스턴스가 하나일 때만 정확합니다. 여러 인스턴스로 배포하면 Redis 등으로 바꾸세요.
- 문장삽입은 6문장 이상, 무관한 문장은 5문장 이상, 순서배열은 4문장 이상인 지문에서만 만들어집니다. 짧은 지문이면 해당 유형에 안내 메시지가 나옵니다.
