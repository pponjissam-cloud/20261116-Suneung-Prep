# 설계 노트

## 🔷 1단계: Sam의 구조 분석

**작업 목적과 범위**
- 핵심 목표: 영어 지문 하나를 넣으면 6종의 수능 대비 학습자료를 자동으로 만들어 출력하는 웹앱
- 범위: 1차 버전은 지문 입력 → 생성 → 화면 확인 → 인쇄/PDF. 회원가입·결제 제외
- 결과물: 탭/페이지로 나뉜 6개 섹션 + A4 인쇄용 레이아웃

**모호한 점과 기본값**

| 항목 | 기본값 |
|---|---|
| 분석 엔진 | LLM API (Claude), 서버에서만 호출 |
| 문제 유형 | 수능 영어 독해 주요 유형 중 사용자가 체크해서 선택 |
| 문제 수 | 선택한 유형마다 1문항, 5지선다 |
| 지문 길이 | 영어 80~450단어 |
| 저장 | 1차는 브라우저 localStorage에 최근 10건 |

**구조 설계 원칙**
- 문장 분리는 코드로 먼저 확정
- 모든 섹션이 같은 문장 ID(s1, s2…)를 공유해 섹션 간 불일치 방지

## 🔶 2단계: Jenny의 기술적 강화

- 스택: Next.js 15 (App Router), TypeScript 5 (strict), Tailwind CSS, Zod, Anthropic SDK
- 생성 방식: 섹션별 LLM 병렬 호출, JSON 출력, Zod 검증, 실패 시 최대 2회 재시도
- 정답 편향 방지: 선택지를 서버에서 셔플하고 정답 번호 재계산
- 환각 방지 검증: 단어가 실제 지문에 있는지, 밑줄 위치(오프셋)가 실제 지문 안에 있는지 확인
- 보안: API 키는 서버 환경변수에만, rate limit 적용
- 인쇄: `@media print`로 A4 레이아웃, 섹션별 페이지 나눔

## 🔹 3단계: Will의 최종 검토

- 정답지는 문제 생성 결과로 함께 생성 (따로 만들면 문제와 정답이 어긋남)
- 순서배열·문장삽입은 원문 문장 ID 기준으로 코드가 직접 조립
- 생성에 30~60초 소요 가능 → 섹션별 진행 상태 표시, 실패 섹션만 재생성
- 한 번에 다 만들면 품질 저하 → 구현 순서를 단계별로 지정
